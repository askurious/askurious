# Fonts that come with Askurious

Fonts in this folder are served by Askurious itself, so the pages of a survey load nothing from other servers.
Each font lies in a folder of its own, together with its licence. The files are the unchanged files of the
upstream project.

| Font | Files | Source | Licence |
|---|---|---|---|
| Atkinson Hyperlegible Next | `atkinson-hyperlegible-next/AtkinsonHyperlegibleNext-wght.woff2` (upright, weights 200 to 800), `atkinson-hyperlegible-next/AtkinsonHyperlegibleNext-Italic-wght.woff2` (italic) | https://github.com/googlefonts/atkinson-hyperlegible-next at commit 16d9515c933216b238289718ac7a3b3599b4d990 (2024-11-20; byte-identical, checked by git blob hash 2026-10-23), `fonts/webfonts/AtkinsonHyperlegibleNext[wght].woff2` and `AtkinsonHyperlegibleNext-Italic[wght].woff2` (renamed without brackets) | SIL Open Font License 1.1, `atkinson-hyperlegible-next/OFL.txt`. Copyright 2020-2024 The Atkinson Hyperlegible Next Project Authors |

The SIL Open Font License allows bundling and redistributing a font with software as long as the copyright notice
and the licence go with it; that is the file `OFL.txt` next to the font files. The font must not be sold by itself.
When a font is added or updated, keep its licence file beside it and add a row here.
