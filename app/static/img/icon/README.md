# Icons

`icon-512.png`, `apple-touch-icon.png`, `../../favicon.ico` and the README logo `docs/logo.png` / `logo-dark.png`
show the letter "A" and the word "Askurious" in **PT Serif Bold** (© 2010 ParaType Inc., SIL Open Font License 1.1,
from google/fonts `ofl/ptserif/PT_Serif-Web-Bold.ttf`), white on #1C1C1A or in #1C1C1A / #E7E5E0, the same font
as the Android app's icon. Rendered with Pillow on 2026-10-16; earlier versions were set in Iowan Old Style, a
commercial font whose licence does not clearly cover a logo (copyright audit 2026-10-16, U19).
The wordmark on the pages (`../wordmark.svg`, header, footer, start page, participants' pages, status page) is the
same font as outlines, made with fontTools from that file on 2026-10-22 (templates/_wordmark.html); before, the pages
named Iowan Old Style as text (copyright audit 2026-10-22, R5/L13). Images made with the font, not the font itself:
the font file is not shipped. The POLLtergeist icons are drawn from the own ghost (templates/_ghost.html).
It follows the app's own ghost of the live polls' big screen (live.js, drawn in this project, commit b69e723b).
