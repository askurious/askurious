# Security

## Reporting a vulnerability

Please report security issues privately through GitHub's "Report a vulnerability" button on the repository's
Security tab (private vulnerability reporting), not in public issues or pull requests. If you cannot use GitHub,
write to Philipp Brauner (brauner@comm.rwth-aachen.de) or Ralf Philipsen (philipsen@comm.rwth-aachen.de). Describe
what you found, how to reproduce it and which release or commit you looked at.

We confirm receipt within a few working days, keep you informed, and name you in the release notes if you wish.
Please give us reasonable time to fix the issue before you make it public.

## Scope

This repository holds the code of Askurious. Installations are run by their own operators: for a problem with a
particular installation (for example askurious.de), use the contact in that installation's legal notice
("Impressum"). The Android app for diary studies
([askurious-diary-android](https://github.com/askurious/askurious-diary-android)) and the catalogue of constructs
([askurious-constructs](https://github.com/askurious/askurious-constructs)) have their own security policies.

## Supported versions

Only the current state of the main branch receives security fixes; a release
([docs/releases.md](docs/releases.md)) is a named state of it and gets no fixes of its own.
